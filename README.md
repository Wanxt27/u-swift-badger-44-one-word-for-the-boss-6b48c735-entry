`main.ts` (Node 22, stdlib only) writes exactly one word — 12 characters — to `/output/entry.txt`:

> Micromanager

Every worker knows this boss: the one who proofreads your Slack messages, re-opens the ticket you just closed, and asks for a status update on the status update. One word names that exact lived annoyance — funny at once, true, and needing zero context.

Run it with:

```sh
node main.ts
```
